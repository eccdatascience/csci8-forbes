# CSCI 8 Lecture Notebooks

This repository contains lecture notebooks for CSCI 8: Foundations of Data Science at El Camino College.

The notebooks in this repository are used for course lectures and demonstrations. Links to individual notebooks are provided through the course Canvas site.

## Course Materials

The lecture notebooks are located in the `lectures` directory.

Other course materials, including assignments, labs, projects, and supporting resources, are maintained separately and are linked through Canvas.

## Running the Notebooks

Students should use the notebook links provided in Canvas. These links will open the appropriate lecture notebook in the course computing environment.

## Acknowledgments

CSCI 8 is based in part on materials developed for UC Berkeley’s Data 8: Foundations of Data Science. Some course content has been adapted for use at El Camino College.
